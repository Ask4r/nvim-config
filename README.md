# Prerequisites

Install `luarocks`, `tree-sitter-cli`, `ripgrep`.
Optional `wget`, `fd`.

# Managers

Lazy package manager `:Lazy`
Mason binaries manager `:Mason`
Something wrong... `:checkhealth`

# Troubleshooting

Cleanup cache

```sh
rm -rf ~/.local/share/nvim/
rm -rf ~/.local/state/nvim/
rm -rf ~/.cache/nvim/

```
